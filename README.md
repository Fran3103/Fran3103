## 🚀 Proyecto principal

### [CocktailOps](https://github.com/Fran3103/CocktailOps)

Sistema web para calcular órdenes de insumos y bebidas para eventos de coctelería.

El sistema permite seleccionar cócteles, calcular ingredientes necesarios, generar órdenes, consultar historial de usuario y descargar PDFs con listas de compra.

#### Backend

- API REST con **Java y Spring Boot**
- Base de datos **PostgreSQL**
- Migraciones con **Flyway**
- Autenticación con **Spring Security + JWT**
- Roles `USER` y `ADMIN`
- Creación pública de órdenes para visitantes
- Asociación de órdenes a usuarios autenticados
- Historial de órdenes por usuario
- Protección de PDFs por ownership
- DTOs para requests y responses
- Documentación con **Swagger / OpenAPI**
- Tests unitarios con **JUnit 5 y Mockito**
- Docker Compose para entorno local
- CI con GitHub Actions

#### Frontend

- **React + TypeScript + Vite**
- **Tailwind CSS**
- React Router
- Axios
- Login y registro conectados al backend
- Consumo real de API REST
- Catálogo de productos y cócteles
- Flujo de creación de órdenes
- Historial de usuario
